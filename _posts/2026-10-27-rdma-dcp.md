## Key Idea

The key problem is that traditional RDMA relies on lossless networks while existing lossy RDMA solutions suffer from inefficient retransmissions and limited support for packet-level load balancing. The paper's core contribution is DCP, a transport architecture that separates the lossless control plane from the lossy data plane by using packet trimming, allowing precise loss recovery without relying on retransmission timeouts.

## Critique

The paper convincingly demonstrates that DCP can significantly improve RDMA performance in lossy networks, achieving up to 2.1x improvement over exisitng lossy RDMA solutions. However, DCP requires modifications to both switches and RNICs, which may make widespread deployment difficult. Furthermore, its reliability also depends on maintaining an effectively lossless control place, which assumes ideal conditions thus be challenging under extreme congestion/hardware failures.

## Connections

This paper connects with dcSim and DCTCP as all three explore different approaches towards improving specifically datacenter network performance. dcSim uses a simulation approach via proactive probing to prevent packet loss while DCTCP uses ECN feedback to control congestion. DCP chooses a different approach in which it accepts packet loss and rather focuses on recovery. I wonder it DCTCP can be used in conjunction with DCP to allow for a efficient congestion control protocol that can also recover loss data, enabling maximnum efficiency.
